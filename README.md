# interview-review

一个用于系统复盘面试记录的中文 Skill。

它可以将面试录音转写、面试笔记或问答记录整理为结构化复盘，帮助你还原现场回答、识别面试官的重点追问，并准备下一次更好的回答。

## 核心能力

- 按主题整理面试问题和追问链
- 详细保留候选人的原回答
- 分析回答中的亮点、漏洞和失分点
- 在不篡改事实的前提下提供优化回答
- 识别面试官关注的能力和岗位要求
- 输出整场诊断、核心短板与准备优先级

特别适用于 AI 产品、策略产品、商业化、Agent 和模型产品相关面试。

## 使用方式

向支持 Skills 的 AI 助手提供面试记录，并要求使用 `interview-review` 进行复盘。例如：

> 请使用 interview-review 复盘这份面试转写，保留我的原回答，并给出逐题点评和优化答案。

具体复盘规则请查看 [SKILL.md](./SKILL.md)。
